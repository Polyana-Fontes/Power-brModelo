# Power brModelo

Rewrite of https://sourceforge.net/projects/brmodelo30/ in Kotlin Compose Multiplatform.

License: GPLv3

Targets:
- Desktop (`jvm`)
- Web (`wasmJs`)

How to run:
- desktop: `./gradlew :composeApp:run`
- web (dev): `./gradlew :composeApp:wasmJsBrowserDevelopmentRun`
- web: `./gradlew :composeApp:wasmJsBrowserDistribution`
